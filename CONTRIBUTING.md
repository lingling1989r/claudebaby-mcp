# Contributing

Useful contributions include reproducible connection fixes, dated capability checks, source-linked research examples and documentation translations. Please separate observed behaviour from suggestions.

For a bug, include client/version, platform, tool name, expected result and redacted actual result. Omit keys, account identifiers and private data. For a research example, explain the question, actual records reviewed, missing coverage and how the method can be reused.

Run `python3 scripts/check_docs.py` before a pull request. Hosted-service internals are outside this repository.
