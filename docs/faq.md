# ClaudeBaby MCP FAQ

## Is this the backend source repository?

This is a public integration kit with documentation and examples. The hosted data service is separate. You can use the remote MCP without cloning a backend repository.

## Is the service free because this kit uses MIT?

No. The licence covers these docs and templates. Queries may consume account credits; check [pricing](https://claudebaby.cn/pricing.json) and your console before a large task.

## Does one connection guarantee every platform?

No. Use discovery, your account's tool list and a real query. Live metadata, planned features, account permissions and successful data responses are different signals. See [platform support](platforms.md).

## Can I search Reddit comments or compare 1688 products?

Those are research workflows built with available platform tools. Read the specific schemas and returned records. [Reddit guide](reddit-brand-research.md) and [kit comparison](1688-kit-comparison.md) explain the evidence requirements.

## Does it publish social posts, buy products or automatically produce Excel?

These examples focus on research. Publishing and purchasing require separate tools and authorization. For illustrated workbooks, pair retrieval with the separate [social-case-to-excel Skill](https://github.com/lingling1989r/social-case-to-excel).

## Should I send my API key in an issue?

Never. Send client version, tool name, sanitized parameters and redacted error text. Keep keys in private client credential settings, not URLs or screenshots.

## Is WorkBuddy support already live?

The v1.0.1 submission was under review on 2026-10-13. [WorkBuddy guide](workbuddy.md) distinguishes the submission from public market availability.

## What makes a research conclusion trustworthy?

Source links, dates, sample boundaries and separation of original statements, reported effects and inference. Likes do not prove sales; search-list prices do not prove kit contents or profit.
